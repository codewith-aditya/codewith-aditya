## What I'm building

**[Astra AI Gateway](https://modelrouter.in)** — an OpenAI-compatible gateway that fronts dozens of models behind one endpoint: streaming, tool calling, per-key balances and plans, provider-aware routing.

**[agy-bridge](https://github.com/codewith-aditya/agy-bridge)** — run Google Antigravity (CLI and IDE) against any OpenAI-compatible model, in Go, single static binary, no dependencies.

**[Tantra AI Labs](https://tantra-ai-labs.com)** — voice and speech tooling, including a self-hosted TTS stack.

## Shipped

- **[AstraGPT-7B](https://github.com/codewith-aditya/AstraGPT-7B)** — 7B decoder-only LLM built from scratch (GQA, RoPE, SwiGLU) with its own BPE tokenizer, LoRA reasoning fine-tune. [Weights on Hugging Face](https://huggingface.co/adityawakharkar/AstraGPT-7B).
- **LLM moderation API** — a 15-category content classifier over a served Qwen3 model, exposed as a REST service.
- **Atlas AgriSense** — an ESP32 + Arduino field-monitoring stack with a cloud dashboard.

## Open source

Merged contributions to **rakazo** (messaging delivery lanes, mobile ticket board, approval expiry configurable, clearer bot-resolution errors) and an open PR to **qwen-code**.

## Stack

`Go` `TypeScript` `Python` `SQL` · vLLM · Postgres · Redis · Docker · Linux · Nginx
